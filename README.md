## 📂 Public Projects

### 🏥 [MedPlanner](https://github.com/douglasstorrer/medPlanner)

A clinic appointment management application built with **Angular and Spring Boot**.

The project includes:

- JWT-based authentication
- Appointment scheduling and management
- Patient, doctor, specialty, and user management
- Spring Boot REST API
- Spring Data JPA / Hibernate
- Angular frontend
- Docker Compose
- H2 database
- Automated tests

**Tech:** Java · Spring Boot · Angular · TypeScript · JPA/Hibernate · H2 · Docker

This project is being developed as a practical demonstration of fullstack application development, backend architecture, REST APIs, authentication, testing, and containerized development.
